提示词相关知识 ​

提示词概述 ​

提示词（Prompt）是针对大模型的输入，是用户提供的文本指令或问题，用于引导模型理解任务需求并输出符合预期的结果。类似于人类对话中的提问或指令，是大模型与用户交互的 “桥梁”。

提示词的核心作用 ​

任务定义 ​

明确告知模型需要执行的任务类型，例如问答、写作、翻译或编程等，确保模型能够聚焦任务需求。

上下文设定 ​

通过提供任务的背景信息，帮助模型理解上下文语境，从而缩小思考范围，产出更贴合需求的答案。

输出控制 ​

通过格式、风格、长度等要求，精确约束生成内容的结构，确保输出内容符合预期的规范和标准。

为什么提示词重要 ​

提示词质量的影响 ​

大模型本质是 “无预设目标” 的概率生成器，提示词的质量直接影响输出的准确性和相关性。

提示词与模型性能 ​

好的提示词能激发模型的潜力，差的提示词可能导致答非所问或低质量结果。

提示词的常见类型 ​

指令型 ​

清晰明确任务指令，如 “请总结这篇文章的核心观点” 后附文章内容，引导模型专注完成任务。

角色扮演型 ​

设定模型身份，如 “假设你是一位历史学家” 引导模型从特定视角出发，增强内容专业性。

问答型 ​

以问题形式激发模型知识探索，如 “为什么天空是蓝色的？” 促进模型与用户的知识交流。

示例驱动型 ​

提供详尽的输入输出示例，引导模型通过 Few-shot Learning（少样本学习）模仿生成内容。

结构化提示 ​

结合格式要求，如 “生成包含标题、大纲和结论的演讲稿”，引导模型结构化输出信息。

有效提问的五个黄金法则 ​

（一）明确需求 ​

  • ❌ 错误示例：「帮我写点东西」
  • ✔ 正确姿势：「我需要一封求职邮件，应聘新媒体运营岗位，强调 3 年公众号运营经验」

（二）提供背景 ​

  • ❌ 错误示例：「分析这个数据」
  • ✔ 正确姿势：「这是一家奶茶店过去三个月的销售数据，请分析周末和工作日的销量差异（附 CSV 数据）」

（三）指定格式 ​

  • ❌ 错误示例：「给几个营销方案」
  • ✔ 正确姿势：「请用表格形式列出三种情人节咖啡店促销方案，包含成本预估和预期效果」

（四）控制长度 ​

  • ❌ 错误示例：「详细说明」
  • ✔ 正确姿势：「请用 200 字以内解释区块链技术，让完全不懂技术的老人能听懂」

（五）及时纠正 ​

当回答不满意时：

  • 「这个方案成本太高，请提供预算控制在 500 元以内的版本」
  • 「请用更正式的语气重写第二段」

代码提示词 ​

（一）模块 1：代码调试 ——5 分钟精准排错 ​

1. 三步终结 BUG 法 ​

🚀 步骤 1：错误信息翻译 ​

指令模板 ：

【错误诊断模式】
我遇到 [编程语言] 报错: "粘贴错误信息"
请:
1. 用小白能懂的话解释问题本质
2. 标注可能引发该错误的 3 个常见场景
3. 给出最可能的修复方案 (标 ★) 和其他备选方案

案例 ：

报错: Python 的 IndexError: list index out of range

→ 人话解释: "就像试图从只有 5 个座位的电影院票根上找第 6 排的座位"

→ 高频场景：循环条件错误 / 动态删减列表 / 索引计算失误

→ 修复方案：在访问前添加 if len(your_list) > index: 条件判断

🚀 步骤 2：上下文分析 ​

进阶指令 :

结合上下文代码片段:
[粘贴相关代码]
请:
1. 用箭头图画出变量值变化轨迹
2. 在可疑行号旁标注 ● 并说明原因
3. 输出修改后的代码差异对比 (用绿色 +/ 红色 - 标注)
🚀 步骤 3：防御性编程 ​

防复发指令 :

针对这个错误类型:
1. 设计 3 个单元测试用例 (含边界条件)
2. 生成代码片段：自动检测同类错误的防护性代码
3. 推荐 2 个相关调试工具 (VS Code 插件 / Python 库)

遇到复杂错误时，追加指令 “用厨房做饭的比喻解释这个问题” 快速理解本质

2. 驱动类型技巧 ​

提供输入 - 输出示例，让模型模仿已知模式，助力精准生成相关内容。

提示词示例 ：

你是一名电商客服助手，请严格按以下示例格式回答用户关于退货的问题：

【示例】用户问：“怎么退货？”回答：“您好！根据我们的退货政策（条款 3.2），您需满足以下条件：

步骤 1：登录 APP，进入‘我的订单’；

步骤 2：选择订单 → 点击‘申请售后’→ 提交退货原因；

现在请回答用户问题：用户问：“”

3. 结合关键词技巧 ​

在提示词中巧妙嵌入关键词，确保生成的内容与关键词紧密相关，提升准确性。

提示词示例 ：

提示词：客户询问耳机退货政策时，请用生活化语言解释退货条件和步骤，回复中需包含关键词：七天无理由、未拆塑封、运费险。

（二）不同场景下提示词示例 ​

场景 2：故障处理引导 ​

目标 ：采用共情策略，逐步引导用户检查，避免技术术语，确保沟通顺畅。

提示词设计 ：

角色：家电维修客服专家

任务：根据用户描述的冰箱不制冷问题，按以下逻辑生成回复：

共情确认："非常理解您的不便，我们先做几个简单检查"

分步骤引导（最多 3 步）：

步骤 1：检查电源插头是否松动

步骤 2：确认温控器是否设定在 2 - 4 档

步骤 3：听压缩机是否有嗡嗡声

结果判断：

若任一步骤发现问题 → 指导解决方法

全部正常 → 提供预约维修链接

禁用词汇：故障代码、拆机、保修期外费用

技术面试 —— 精准打击考点 ​

备战体系构建 ​

🚀 考点预测

指令 :

根据 [目标公司] 近 3 年面经和我的技术栈: [Java/Python/Go...]
输出:
1. 高频考点 TOP10 (按出现频率排序)
2. 对应 LeetCode 题号 (标注原题 / 变式题)
3. 系统设计重点领域 (附学习路线图)

生成题目 :

给我一道中等难度的二叉树题目，要求:
- 包含递归和非递归两种解法
- 设置 2 个易错测试用例
- 附带时间复杂度分析要点
模拟面试: ​
现在开始面试模拟:
1. 请用伪代码描述思路 (计时 10 分钟)
2. 我会指出 3 个潜在 bug，请现场修复
3. 最后给出优化建议 (空间换时间策略)
智能反馈: ​
根据我的代码: [粘贴代码]
请:
1. 按大厂评分标准给出 ABC 等级
2. 标注代码亮点 (如优雅的边界处理)
3. 指出可能扣分的坏味道 (如魔法数字)
